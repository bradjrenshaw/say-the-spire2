* Added support for the new Dread mode in the beta. I am nowhere near good enough at the game to reach Dread myself (it is hidden until you have reached ascension 10 on every character), so this has had very little real testing. If you play it, please report anything that does not read or reads incorrectly.
* The Dread character select screen reads each character's current win streak and best streak records. Starting HP and gold are not read there since the Dread screen does not show them. The Dread info popup is read out, including the ten ascension modifiers it lists.
* The "Begin Rotating Streak" checkbox on the Dread screen can only be clicked with the mouse in the game itself. With the mod, press down from any character to reach it, select (enter on keyboard) to toggle it, and up to go back to the characters. The Rotating button reads which character is up next.
* When you return to the Dread screen after a run, the mod announces whether your streak increased or was broken.
* During a Dread run, the boss icon in the top bar reads the act's Dominion (the extra rule that applies to every fight before the boss) along with any cards or keywords it refers to. The ascension control in the top bar reads "Dread" and your streak, and its buffer lists the four Dread rules.
* The Blitz and Dread info popups now behave like proper dialogs. Focus lands on the popup's confirm button after the text is read, the arrow keys no longer move through the characters behind it, and either select or accept closes it. Previously pressing enter on a character while the popup was still open silently did nothing.
* Added support for the Fool, the new character in the beta. Your arrows and melodies are read as part of your resources (in the player buffer and with ctrl y), your arrows are also read when you focus your character, gaining a melody is announced, and each melody you are holding is listed with its description in the player and creature buffers.
* In multiplayer, powers that the game hides from you are no longer read. Some powers exist once per player on the same creature (for example the Fool's Impaled) and the game only shows you your own copy; the mod was reading every copy. Sandpit is still listed for every player, with the player's name, since sighted players can see that from where the characters are standing.
* Starting gold is no longer read on the Blitz character select screen since the game does not show it there. The "Under Construction" notice on the Blitz and Dread screens is now read once when you open them.
* The Continue button on the main menu now reads the summary of your saved run: the character, act and floor, the ascension or game mode, HP, gold and when it was saved.
* The custom run screen's new game mode dropdown is supported. It is between the seed and the characters; select opens the list and cancel closes it without leaving the screen.
* The ascension control in the top bar now also reads the game mode line the beta added, and tells you when achievements and epochs are locked for the run (daily and custom runs).
