* The mod now works with the latest beta of the game. That update broke quite a few things, most noticeably the character buttons on character select no longer reading.
* Added support for the new Blitz mode in the beta. The Blitz character select screen reads the same way as the normal one, including the Blitz ascension levels (there are only 5 and they are shared across all characters.) The Blitz info popup that appears the first time you open the mode is read out; press accept (e on keyboard, y on controller) to close it, and press accept again on the Blitz screen at any time to bring it back up.
* The Blitz merchant is now supported. Instead of selling things for gold, this merchant offers you a set of free items and lets you pick a few of them. Each offer reads its name and description, and the number of picks you have left is read when you open the shop and again after each pick.
* Blitz has no map screen; each act is a fixed line of rooms that is shown as a strip in the top bar instead. Each room on the strip reads its type, whether it is your current location or already traveled, its position in the act (for example 4 of 8), and the game's description of that room type. Pressing up from anywhere on the top bar jumps to the start of the strip so you can check it quickly. Note that the history of rooms you have already visited is not read yet.
* When you proceed to the next room in Blitz, the mod now announces the room you are traveling to, the same as it does when you pick a room on the map in other modes.
* In multiplayer Blitz, the mod now announces when another player is ready to proceed, and tells you when you are marked as ready and waiting on other players.
* There is no gold in Blitz, so the announce gold hotkey now says "No gold in this mode" there and gold is no longer listed in the player buffer.
* Ascension descriptions now always match the mode you are in, both on the character select and custom run screens and on the ascension control in the top bar during a run.
* Fixed a few other things the latest beta broke: map voting in multiplayer, detecting when you are typing in a text box (such as the seed field), and announcing players joining a loaded multiplayer game.
* When poison or doom is going to kill a creature before its next turn, the mod now reads "dying to poison" (or doom) right after the creature's name. The game shows this by changing the color of the creature's health bar. Like other announcements this can be disabled or reordered in the mod settings.
* Fixed a bug where the map room you were focused on at the start of an act would sometimes not be read in multiplayer.
* The new Dread mode is not supported yet. It is hidden in the game until you have reached ascension 10 on every character.
